# Upstream screens as built (survey 2026-11-25, for the snapshot wireframes)

Labels from `messages/en.json`; layout from `src/components/*`, `src/app/*`. Snapshots show these **after the M1 restyle**: Cornerstone frame (S-frame), light only, Broadcasts / AI Agents / signup / theme picker (Settings › Appearance, header toggle) hidden. Layout otherwise unchanged.

- **Shell:** sidebar 240 (Dashboard, Inbox, Notifications (badge, 9+), Contacts, Pipelines, Broadcasts, Automations, Flows (BETA), AI Agents | Settings); footer account strip + user row menu (Profile, Settings, Sign out). Top bar 56: page title, theme toggle, avatar menu. Banners: "This user is not linked to an account"; "Could not load your permissions" [Retry]. Phone: drawer.
- **S-login** (/login, /forgot-password, /reset-password): centred card. Login "Welcome back" / "Sign in to your account"; Email, Password + "Forgot password?"; [Sign in]; footer "Don't have an account? Create account" (hidden in v1: invite only); expired-link alert. Forgot: "Reset password", Email, [Send reset link] → "Check your email". Reset: "Choose a new password", New + Confirm, [Update password]; states "Checking your link...", "This link is no longer valid" [Request a new link], "Password updated" [Continue to dashboard].
- **S-join** (/join/[token]): card. "Verifying invitation…"; "You're invited to {account}" · "You'll join as [role]. Link valid until {date}." [Accept invitation]; signed out: [Create account & join] / "I already have an account"; conflict "Can't join {name} with this account" [Stay signed in] [Sign out & use a different email]; failures: not found, already used, expired, too many attempts, something went wrong.
- **S-inbox** (/inbox): 3 panes list 320 | thread | contact panel 280. Banner "WhatsApp® is not connected…". List: search "Search conversations...", filters Status (All/Unread/Waiting for reply/Unassigned/Reply window closing/Open/Pending/Closed), Tags, Company; row avatar, name/phone, time, preview, unread pill, status dot; empty "No conversations found". Thread: empty "Select a conversation"; header name+phone, "Xh remaining"/"Expired", panel toggle, refresh, status (Open/Pending/Closed), assign; "Load older messages", date separators, bubbles (hover Reply/Copy/React/Delete); composer: attach (Photo/Video/Document/Voice note), More (Interactive message, Quick replies, Save as quick reply), [Templates], textarea "Type a message... (Shift+Enter for new line)", [Send]; "24-hour session expired. Use a template to re-engage."; viewer read-only line. AI draft ✨ and AI banners hidden in v1. Contact panel: avatar, name, company, phone (copy), email, TAGS (+ Add tags), DEALS, NOTES ("Add a note...").
- **S-contacts** (/contacts): "Contacts" / "Manage your contact list. {n} total contacts." [Custom fields] [Import] [Add Contact]; search "Search by name, phone, or email...", "Filter by tags"; bulk "{n} selected" [Clear] [Delete selected]; columns ☐ Name Phone Email Company Tags Created …(Edit, Delete); "Showing 1-25 of N", "Page X of Y". Empty "No contacts yet." [Add your first contact] / "No contacts match your filters." Row → right sheet: header + [Send template]; tabs Details | Tags | Notes | Custom Fields | Deals.
- **S-board** (/pipelines): pipeline selector (+ Manage Pipelines), [Add Pipeline] [Add Deal]; KPI strip Total Deals, Pipeline Value, Avg Deal Size, Weighted Value, Won This Month, Lost This Month; kanban lanes (colour, name, count, total value; "Drop a deal here"; "+ Add Deal"); card: stage-colour bar, title + Won/Lost pill, contact, value + close date, assignee. Deal sheet "Edit Deal": Title, Contact, Link to Conversation, Value, Currency, Expected Close Date, Stage, Assigned To, Notes; [Mark as Won] [Mark as Lost]/[Reopen deal]; [Cancel] [Save Changes]; [Delete Deal]. Empty "No pipelines yet" [Create Pipeline]. M3 changes the card: that is S-lead.
- **S-flows** (/flows): "Flows" + Beta, [New flow]; card: name, Draft/Active/Archived, trigger line, "{n} runs", [Edit] [Delete]; empty "No flows yet". Create dialog: templates Welcome menu, FAQ bot, Lead capture; or blank. Editor: "Back to Flows", name, description, "Unsaved changes", [Runs] [Delete] [Pause/Activate] [Save]; Canvas | List toggle; node legend (Start, Send message, Send buttons, Send list, Send media, Collect input, If / else, Tag contact, Handoff to agent, End); config panel "No node selected"; validation bar "No issues. Ready to activate." Runs page: rows contact, status, "at {node}", "Started {time}".
- **S-automations** (/automations): "Automations" / "Build workflows that react to WhatsApp® events automatically." [Create Automation]; Quick-start templates (Welcome Message, Out of Office, Lead Qualifier, Follow-up Reminder); row: name + active dot, description, trigger pill, "N runs", "last 5m ago", toggle, … (Edit, Duplicate, View Logs, Delete); empty "No automations yet". Builder: back, name, Active switch, [Save]; TRIGGER card (New Message Received, First Message from Contact, Keyword Match, Button / List Reply, New Contact Created, Conversation Assigned, Tag Added, Time-Based); steps with "+ Add step" (Send Message/Buttons/List/Template, Add/Remove Tag, Assign Conversation, Update Contact Field, Create Deal, Wait, Condition, Send Webhook, Close Conversation). Logs: "Execution logs", rows contact, success/partial/failed, "{n} steps".
- **S-dashboard** (/dashboard): "Good morning, {name}"; "N customers are waiting for a reply, the oldest for X."; number health chip; Today/7/30/90 days; [New ▾]. Setup checklist when incomplete (Connect WhatsApp, Add contacts, Template approved, Invite a teammate). Attention tiles: Waiting for a reply, Unassigned, Reply windows closing, Failed messages. KPI tiles + sparkline: New conversations, Median first reply, Resolved, Deals won, Broadcast read rate (hidden in v1). Message volume chart; Reply queue "Longest wait first"; Pipeline "Open deals by stage"; Team table Member | Open | Replies | Median reply; Campaigns and automations (broadcast part hidden); Recent Activity.
- **S-notifications** (/notifications): "Notifications" / "Conversations other teammates assign to you show up here." [Mark all as read]; cards "New conversation assigned", "{actor} assigned you a conversation with {contact}", time, unread dot/tint; empty "No notifications yet".
- **S-settings-upstream** (/settings?tab=): "Settings" / "Everything in one place — your account and your workspace." Draw Team members open: [Invite member]; rows avatar, presence, name, email, "Joined {date}", role select, [Remove]; "Pending invitations" [Revoke]; invite dialog Role, Link valid for 1/7/30 days, Label, [Generate link] → link [Copy] [Send via WhatsApp].
