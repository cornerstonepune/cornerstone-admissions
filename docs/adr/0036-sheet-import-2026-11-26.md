# 0036 — The old admissions sheet imported to live

**Date:** 2026-11-26 · **Status:** accepted (Nimish, in chat: "can we ensure we are importing all the families even
without phone numbers with a tag", then "Yes, import all")

## Context
Cornerstone's current pipeline lived in a Google Sheet (tab "Query Pipeline Flow", columns M–T: class, parent, child,
age, phone, source, free-text status). It had 70 rows, no enquiry dates, 8 families without a usable phone, 5 duplicate
rows and 4 already-admitted families. `import_leads` (116, 117) dedupes by phone, marks `imported_at`, refuses Admitted
and has no note or exit.

## Decision
- **No code change.** One transaction on the hosted DB as the owner (RLS applied): `import_leads` for every family →
  the column-T comment into `deals.notes` (the lead panel's Notes) → Lost families closed as `closeLead` does →
  Admitted families imported at Applied, then `move_lead` (sets `admitted_at`) → wacrm contact tags. Dry run with a
  forced rollback first.
- **Every family is kept.** A family without a phone gets a placeholder phone `+00000000NNNN` (no country code 0, so
  never a real number), the tag **No phone**, and a first note line saying so. A number staff marked invalid keeps its
  digits with the tag **Check phone**. Non-admission enquiries (venue hire, after-school activities) are contacts only,
  tagged **Not admissions** / **After-school**, with their comment as a contact note; they are not on the board.
- **Admitted families are imported** (overrides ADR 0027's "only live enquiries" for this import).
- **Reading the sheet:** fee follow-up = Applied; still deciding after fees = Deciding; meeting done = Visited;
  meeting fixed = Visit booked; joined elsewhere / "only CBSE" / too young = Lost, Chose another school; distance =
  Lost, Distance; K1 = Jr KG, K2 = Sr KG; Daycare and Playgroup–Sr KG = Neev, Grade 1+ = Gurukul. Duplicate rows merge
  into one lead with every comment; a phoneless sibling is a note on the family's lead.

## Consequences
- Live after import: 59 leads (Enquiry 31, Visit booked 2, Visited 4, Deciding 2, Applied 3, Admitted 7, Lost 10),
  3 contact-only records; no messages sent, no follow-ups (imported leads are skipped, ADR 0029).
- With no enquiry dates, all 59 count as November 2026 enquiries in the report, and the 7 admitted as November
  admissions.
- A "No phone" family who later writes from their real number opens a second lead; staff put the real number on the
  original contact and delete the new one.
